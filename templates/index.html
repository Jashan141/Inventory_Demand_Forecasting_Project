Machine Learning Architecture & Methodology

Educational guide explaining the machine learning pipeline, mathematics, and operational workflow.

1. Random Forest Regressor

An ensemble learning algorithm combining multiple decision trees (bagging). It prevents overfitting, handles non-linear customer purchasing trends, and captures complex feature interactions effortlessly.

  • Trees (n_estimators): 100
  • R² Accuracy Score: {{ metrics.r2 if metrics else '0.857' }}
  • Mean Absolute Error: {{ metrics.mae if metrics else '3.55' }} units

2. Engineered Features

To model temporal seasonality and purchasing momentum, the dataset is transformed into rich predictive features:

  • Calendar Signals: Month, Day, Day of Week, IsWeekend, Quarter, DayOfYear
  • Momentum Lags: 7-day and 14-day lagged sales figures
  • Moving Average: 7-day rolling window mean sales

3. Safety Stock Formula

Protects businesses against supplier delays and sudden demand surges using statistical service levels:

Safety Stock = Z × σ_daily × √(Lead_Time)

Where Z = 1.65 (95% service cycle confidence), σ_daily is the standard deviation of daily demand, and Lead_Time is supplier delivery days.

4. Reorder Recommendation Logic

Calculates the optimal replenishment units to prevent both stock-outs and excessive holding costs:

Reorder Qty = (Predicted Demand + Safety Stock) − Current Stock

If Reorder Qty > 0, status is flagged as Reorder Required. If Current Stock ≤ Safety Stock, a Critical Alert is raised.
